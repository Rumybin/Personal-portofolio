# Design Direction

## Chosen Direction
Minimal Swiss + Technical

## Why This Direction
- Fits a professional portfolio.
- Supports readable storytelling.
- Works well for a split-screen narrative layout.
- Makes projects feel deliberate and credible.
- Avoids generic AI-style visual noise.

## Visual Traits
- Strong typography.
- Generous whitespace.
- Neutral surfaces.
- One restrained accent color.
- Clear hierarchy.
- Minimal but precise motion.
- Technical storytelling without dashboard overload.

## Content Language Note
Content will mix Indonesian and English naturally based on context (e.g. technical terms stay in English). This is a content/voice decision, not an i18n/routing decision. No bilingual structure, locale switching, or content duplication is required for Phase 1.

## Homepage Behavior
- Split-screen layout with left and right panels.
- Left side stays anchored with identity and portrait content.
- Right side changes by slide.
- Each slide should have one clear purpose.
- Animations should support understanding, not distract from it.

## Motion Rules
- Use smooth transitions.
- Prefer subtle fade and translate motion.
- Reveal elements progressively.
- Avoid excessive parallax.
- Avoid motion that slows reading.

## Content Rules
- Home should not be a long wall of text.
- Projects should be introduced as a sequence.
- Each project slide should answer what, why, and link.
- The node visual section should act as a closing transition or conceptual map.
